使用方法

操作步骤

  1. 写公式

    在编辑区直接输入，或选择分数、根号等模板。键盘中央是单击输入的符号，右上角灰色小标签提示 Shift 次级符号。长按有变体的按键，保持按住并移到目标符号，松开即可输入；移到选项外松开则取消。模板上的 x、n 是示意，点击后仍可填写。

  2. 选公式、加说明

    按领域浏览常用公式，点击后会替换当前公式和说明。清空或替换后可点“恢复上次内容”。展开“LaTeX源码和补充说明”可编辑 LaTeX、补充变量含义和单位。

  3. 复制到目标应用

    复制公式与说明，附带先复述公式、检查歧义的提示； 仅复制原始 LaTeX。

  4. 粘贴后核对

    在目标对话或文档中粘贴，检查符号、上下标和作用范围。自动复制无效时，点“手动复制”，再复制选中的文本。

源码与输入边界　支持裸 LaTeX、完整数学分隔符与单个 LaTeX 代码块。源码不完整或指令未识别时，保留原文并暂停预览。公式与说明各限 10000 个字符单位，显式括号分组和连续控制指令各限 64；超限暂停相应操作，不截断输入。

关闭前先复制　内容仅保留在当前页面，不保存草稿，不调用 AI。工具不检查数学推导或单位，也不识别图片。复制提示表示浏览器请求的结果，请以目标应用中实际粘贴的内容为准。

快捷键

Windows / Linux 使用 Ctrl，macOS 使用 ⌘；Alt 在 Mac 键盘上对应 ⌥。编辑快捷键作用于当前获得焦点的公式或输入框。

导航与选择

Shift / 屏幕 ⇧
按住实体 Shift 切换次级符号；屏幕 ⇧ 单击切换下一次输入，双击锁定，再点取消。
Tab / Shift + Tab
前往下一个 / 上一个模板空位；没有空位时按页面顺序移动焦点。
← → ↑ ↓
在公式结构中移动光标，例如分子、分母和上下标。
Shift + 方向键
沿对应方向扩展选区。
Home / End
移到公式首尾；加 Shift 扩展选区。Mac 也可用 ⌘ + ← / →。
领域标签上的方向键
← / → 切换相邻领域；Home / End 切换到第一个 / 最后一个领域。

编辑与复制

Ctrl / ⌘ + A
全选当前编辑区内容。
Ctrl / ⌘ + Z
撤销当前编辑区的编辑。
Ctrl / ⌘ + Shift + Z
重做；Windows / Linux 也可用 Ctrl + Y。
Ctrl / ⌘ + C
复制选区；也用于复制“手动复制”框中选中的文本。
Ctrl / ⌘ + X
剪切当前选区。
Ctrl / ⌘ + V
粘贴剪贴板内容。
Backspace / Delete
删除光标前 / 后的内容，或删除选区。
Ctrl / ⌘ + Enter
复制整条公式与补充说明，与编辑区的“复制公式与说明”按钮相同。

公式结构与命令输入

^ / _ / /
在公式中输入上标 / 下标 / 分数。
\ / Esc
在公式区进入 LaTeX 命令输入；再次按 Esc 确认并退出命令输入。
命令输入时 ↑ / ↓
选择上一条 / 下一条自动补全建议。
命令输入时 Tab / Enter
接受当前建议 / 确认完整命令。
命令输入时 Shift + Esc
取消本次命令输入。
矩阵中 Alt + Tab
向右增加一列；再加 Shift 则向左增加一列。系统若截获 Alt + Tab，此组合不会到达页面。
矩阵中 Alt + Enter
向下增加一行；再加 Shift 则向上增加一行。
