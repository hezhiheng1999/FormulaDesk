浏览器测试通过临时的 127.0.0.1 预览进行，服务只提供指定成品与测试夹具。正常宽窗口实际视口为 1265 × 720；窄窗口在 520px 的同源 iframe 中实测，排版组件正常运行、无横向溢出，顺序为编辑、复制、示例，数学键盘位于容器内。没有把未生效的窗口调整请求算成测试通过。

复制验证分开记录：原生“手动复制”后，测试工具读回的内容与完整目标文本逐字一致；正常自动复制的 API 请求与成功提示已观察，但自动复制的真实系统剪贴板内容没有独立确认。拒绝剪贴板权限的夹具中，手动复制仍完整往返；延迟夹具用受控的模拟写入验证防重复和内容变更提示，不代表真实剪贴板写入。

异常场景包含未闭合分式、左右定界符、矩阵、未知命令、链接/HTML 扩展、10001 字符公式、超长说明、混合括号、补充平面字符和 8003 字符的连续根号粘贴。被拒绝的原文保留，旧公式预览隐藏；恢复操作能同时找回公式与说明。组件缺失夹具验证源码编辑与原生手动复制仍可工作。

## 复现自动检查

在项目根目录运行：

~~~text
node --test
python -m unittest discover -s tests -p "test_*.py"
python build.py
python checks/check_bundle.py
python tools/package_release.py
~~~

测试使用项目内独立临时副本；普通测试和构建不下载依赖。发布脚本检查实际公开文件的常见个人路径/密钥形态、文档链接、ZIP 成员白名单和 CRC。详见[开发说明](development.md)与[发布说明](releasing.md)。

## 发布前手动检查

1. 将 portable ZIP 完整解压到新目录，双击 index.html；Windows 另检查 open-formuladesk.cmd。确认断网后字体、示例和数学键盘仍正常。
2. 依次输入分式、积分、求和与矩阵，用 Tab/Shift+Tab 经过模板和后续控件。窄窗口检查按钮和键盘末行可访问。
3. 粘贴完整 LaTeX 分隔符、未写完的公式、未知命令和超限输入。检查原文、提示与预览状态，再修正输入验证能继续工作。
4. 填写公式与说明，载入示例、清空、恢复。检查两部分内容都保留；提醒只保护当前页面，不替代备份。
5. 复制到实际目标应用，逐字核对。拒绝自动复制权限后检查“手动复制”，再测试复制等待期间修改内容和重复点击。
6. 从 source ZIP 在新目录离线重建，检查 HTML 哈希与报告一致；阅读实际 ZIP 清单，检查截图、许可证、联系方式与公开内容。
