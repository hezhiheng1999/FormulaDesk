# FD-005 · 可编辑公式库与矩阵输入设计

本设计依据已确认的两项需求和公式库保存选择。界面细节为实施建议，配套草图与本机核查材料保存在忽略的任务目录。

## 目标与使用方式

用户可管理领域和各领域中的公式，包括新增、删除、改名、编辑内容和调整顺序；能从明确的“矩阵”入口选择尺寸，并在已有矩阵中增删行列。维持离线、无账号、便携的使用方式。

保留公式原文、说明、复制降级、恢复、工作单、快捷唤出及已修复的键盘焦点与高度行为。任务不升级 MathLive，不改写历史发布包或本机正式版。

## 方案取舍

- 保存方式已由用户选择：Windows 浮窗保存到程序旁的独立库文件；独立网页保存在当前浏览器；双方使用同一文件格式导入、导出。相比每次手动打开文件，更适合常用库；相比记住任意外部路径，整个目录更容易搬迁。
- 界面建议：常用公式面板内分为浏览与管理两种视图。浏览保留紧凑按钮，管理展开清单和表单。没有采用常驻双侧栏：400 像素浮窗中会挤压公式和编辑区。
- 矩阵建议：工具栏保留有文字的“矩阵”按钮，展开就近操作区。新矩阵选择行、列和括号；已有矩阵以光标所在单元格为基准操作。相比依赖快捷键，该入口可发现且不会被 Windows 的 Alt+Tab 截获。

## 公式库界面

常用公式面板顶部为搜索框与“管理”按钮。领域标签保留一级选择，并用“全部领域”选择控件容纳完整目录；窄窗不让全部领域撑开许多行。每页六条公式，显示领域内或搜索结果数量和页码。搜索匹配名称及说明，可选择当前领域或全部领域。

浏览、搜索、翻页、管理目录均不改写当前公式和说明。只有明确点击“载入”或浏览中的公式按钮才替换工作区，并保留现有“恢复上次内容”机制。

“管理”中提供“管理领域”和“管理公式”两个子视图：

- 领域：新增、名称编辑、上移、下移、删除；删除前说明包含多少条公式。
- 公式：选择领域；新增、名称/原始 LaTeX/说明编辑、上移、下移、删除。提供“从当前公式添加”，只有用户主动点击才读取工作区。
- 排序使用可见的上移、下移按钮，键盘和触屏都可完成，不依赖拖动。边界按钮禁用。
- 修改留在编辑副本中；“保存修改”成功后才更新当前库和持久副本，“取消修改”丢弃本轮修改。存在未保存修改时离开管理需要选择保留编辑或放弃。
- 支持撤销本轮最近一次目录操作；删除和恢复内置库先显示影响，再由明确按钮确认。取消不发生写入。
- 公式编辑保留原始源码。预览及语法提示沿用输入保护，未完成公式可原样存入私人库，但清楚显示不能预览的原因。内置公式必须全部通过固定解析器。

## 保存、迁移与内置库

Windows 默认文件为 EXE 同目录的 `FormulaDesk.library.json`，只在用户保存库修改或确认导入时写入。启动只读取此文件；不存在时使用内置库，不为了浏览而创建私人文件。写入采用同目录临时文件和原子替换，保存上一次有效文件为备份；失败明确提示，编辑副本保留，不能显示“已保存”。

独立网页使用独立的浏览器本地存储键。该副本属于当前浏览器及页面来源，清理浏览器数据、变更文件位置或更换浏览器可能无法找回；界面提示使用导出文件迁移。存储不可用或容量不足时保留本次编辑，并提供导出，不静默改成已保存。

导出包含当前完整目录、顺序、公式原文和说明，以及格式版本；没有工作区、剪贴板、日志、路径或账户信息。导入先检查文件类型、结构、唯一标识和大小，预览领域数及公式数，明确确认后替换当前库。取消和非法文件保持原库。保存失败保留编辑内容；不得在后台上传文件。

内置库是只读底本，用户修改后的库是独立的完整副本。升级默认不混入新预设，不覆盖删除、改名或排序。提供“恢复内置库”，明确说明它会替换自定义库，并可在保存前取消或撤销；先导出可长期保留旧库。运行期用户文件和浏览器存储均不进入发布包。

启动发现自定义文件损坏时显示错误并保留文件，不将默认库写回坏文件。允许查看内置库，并通过明确的恢复备份或导入动作重新建立可保存的库。

## 默认内容

建议 12 个领域、每领域 30 条，共 360 条：基础代数与三角、微积分、线性代数、概率论、数理统计、信号与系统、数字信号处理、通信原理、相干光通信、电路与电子学、经典力学、电磁学。

每条包含清楚名称、原始 LaTeX、变量与条件说明。各领域按概念覆盖规划，避免仅更换符号、系数或展开同一公式凑数。解析、排版与复制检查覆盖全部预设；数学含义另按领域审阅，特别核对傅里叶约定、复共轭、能量归一化、单位及适用条件，记录实际核查范围。

## 矩阵交互与内容保护

按用户试用反馈，浮窗快捷栏沿用原版矩阵图标和样式，不额外显示按钮文字；悬停提示说明插入或编辑矩阵。打开时保留公式光标与选区；关闭后可继续输入。新矩阵默认 2 行 2 列，允许输入整数行列数，选择方括号、圆括号、行列式竖线或无括号；显示尺寸及空位示意后点击“插入”。新增行和列均显示可填写的空位格子。

已有矩阵：先把光标放入目标单元格，“矩阵”操作区显示当前尺寸与光标所在行列，提供“上方加行”“下方加行”“左侧加列”“右侧加列”“删除当前行”“删除当前列”。未在支持的矩阵中时提示如何定位，并禁用这些按钮，不对公式其他部分执行矩阵命令。

删除前显示受影响行/列及非空单元格数量，必要时列出其源码摘要；明确的“取消”与“确认删除”按钮。保留删除前整条公式和说明供“恢复上次内容”恢复；MathLive 的撤销也应能恢复操作。至少保留一行一列。用户在确认期间改变工作区或光标时，旧删除请求失效，要求重新选定。

初始尺寸建议 1–10 行、1–10 列；固定 MathLive 的默认最大列数为 10。尺寸越界明确提示，不截断或偷偷改写导入的源码。使用固定版的实际命令，运行验证后才认定可用。不自行实现完整 LaTeX 矩阵解析器；只支持该版本能可靠识别和编辑的矩阵环境，分段函数等结构不视为矩阵。

## 视觉与实现约束

用户补充：已有的、与本次改进无关的图标和样式不修改。新增公式支持直接输入；内置及自建公式的名称、内容和领域名均可编辑。

延续现有白纸、浅灰面板和蓝色操作提示：纸面 `#ffffff`、页面 `#f3f4f6`、正文 `#1d1d1f`、次要文字 `#61616a`、分隔线 `#dde0e6`、操作蓝 `#245dd8`。沿用系统 UI 字体与 MathLive 字体，不增加网络字体或依赖。清单左对齐，编辑标签清楚，常用操作保留文字。400/560 像素宽下按单列或紧凑双列重排，长公式允许局部横向滚动，操作按钮不被挤出屏幕。

修改 `src/`，从源码构建成品。数据模型与存储校验可独立测试；页面、宿主和工作区各有明确职责。具体模块划分、字段上限、控件间距由实施者按既有结构决定，不新增未来用途的配置层。

## 可观察验收

1. 两级增删改与排序成功，取消不落盘，保存成功后重启仍在；导出后导入恢复顺序与原文。失败、非法文件、损坏文件和恢复路径有独立证据。
2. 360 条内置公式数量、唯一性、输入保护、固定解析器、排版与复制检查通过；数学含义审阅与语法检查分别记录。
3. 窄窗浏览、搜索、翻页和目录编辑不改变工作区；实际 Windows 浮窗在 400/560 像素下可操作。
4. 矩阵选择尺寸插入、已有矩阵增删行列、取消、撤销和恢复均核对源码；两种复制在独立目标输入框核对实际文本。
5. 适用自动检查及原生回归覆盖首键输入、清空和单行高度稳定、四页等高键盘、长按选择、原文保护、工作单与快捷唤出。
