# 适用范围与兼容性

## 适用场景

- 学习、教学与科研交流中的单个公式、矩阵、积分和简短推导。
- 需要可视化输入，同时向对话、Markdown、LaTeX 或文档编辑器提供公式文本。
- 希望离线编辑，且不需要连接 AI API、运行服务或安装桌面软件。

它不替代完整 LaTeX 排版系统、Word/MathType 文档排版、符号计算器、图片 OCR 或手写识别。目标应用是否将 LaTeX 显示成公式，取决于目标应用；模型仍可能理解错误。

## 平台

| 环境 | 使用方式 | 验证状态 |
|---|---|---|
| Windows + Chromium 类浏览器 | 解压后双击 index.html | 内置 Chromium 的 HTTP 预览已实测；本地文件启动应按手动步骤验证 |
| macOS / Linux + 浏览器 | 解压后双击 index.html | 设计支持；本次没有这些系统的交互实测 |
| Firefox / Safari | 打开独立 HTML | 尚未完成浏览器实测；自动复制可能受限制，可用手动复制 |
| 窄窗口 / 分屏 | 页面自动上下排列 | 测试尺寸与结果见 testing.md |
| 手机 / 平板 | 浏览器可尝试打开 HTML | 虚拟键盘由 MathLive 提供；不宣称完成移动系统认证 |

不依赖 Codex、ChatGPT、Claude 等应用的专有接口。只要目标接受文本，就能粘贴；不保证目标渲染 LaTeX，也不会改变目标应用的输入框。

## 输入与行为边界

- 单条公式最多 10000 个 JavaScript 字符单位，说明最多 10000；显式括号分组最多 64 层，连续不带参数的控制指令最多 64 个。这是资源保护边界，不是完整的 TeX 语义分析。
- 超限后保留原文，停止预览与复制，不截断输入。请缩短后重试。
- 可粘贴裸 LaTeX、完整的 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 或单个 latex/tex/math 代码块。多段公式混排不会被擅自合并。
- 识别不了或未写完的源码保留原文并暂停预览，可继续修改或复制。
- 链接和 HTML 扩展只作为源码保留。公式中的链接不能打开网页，工具也不朗读公式。
- 可视化编辑导出 MathLive 的展开形式，可能统一空格、下标花括号和宏；未识别的源码不会自动转入可视编辑。
- “恢复上次内容”仅恢复最近一次清空或示例/异常粘贴替换之前的公式和说明，不是永久历史记录。
