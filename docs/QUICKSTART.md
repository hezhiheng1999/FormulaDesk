# FormulaDesk 快速使用

1. Windows 浮窗下载 win-x64.zip；独立网页下载 portable.zip。将整个 ZIP 解压到可写文件夹。
2. 浮窗双击 FormulaDesk.exe；网页用浏览器打开 index.html，Windows 也可双击 open-formuladesk.cmd。
3. 可直接点数学键盘输入第一个符号，也可在公式框打字或选择模板。已有 LaTeX 可粘贴到源码区。
4. 选“复制公式与说明”或“仅复制 LaTeX”，在目标输入框粘贴并核对。
5. 自动复制无效时，点“手动复制”，按 Ctrl+C，再到目标输入框粘贴。

无需安装本工具、账号、API Key、Python、Node.js 或本地服务，可以断网使用。Windows 浮窗依赖已有的 .NET Framework 4.8 系列和系统 WebView2 Runtime，默认置顶，图钉控制开关。下载页单独的 EXE 需要 ZIP 的其余文件；请优先下载完整 ZIP。网页可加入浏览器收藏。

清空后，即使切换了下方的面板标签，也可直接点数学键盘继续输入。要找回清空或载入示例前的一组公式与说明，可点“恢复上次内容”。源码未写完或超限时会保留原文，并显示具体提示。

工具不自动保存草稿。网页版关闭或刷新前先复制重要内容。把文件夹移动后，浏览器旧收藏可能需要重新添加。更新时解压新版到单独文件夹、先试用再替换旧文件；卸载只需删除解压出的工具文件夹。

## Windows 浮窗快捷键与工作单

1. 在其他应用按 `Ctrl+Alt+F` 调出浮窗。浮窗在前台时再按一次即可隐藏。再次运行同目录的 EXE 可显示原窗口，右上角的关闭按钮会退出程序。
2. 在“LaTeX源码和补充说明”点击“保存工作单…”或按 `Ctrl+S`，选择位置和文件名。建议保留 `.fdesk.json` 扩展名。覆盖已有文件需要确认，每次保存都可另选位置。
3. 按 `Ctrl+O` 或点击“打开工作单…”。有现存输入时，确认替换后才载入。可用“恢复上次内容”找回替换前的公式和说明。取消或文件错误时可继续原来的编辑。
4. 工作单同时保存 LaTeX 和说明，最多 1 MiB。未写完或超出预览上限的源码也能保存。保存后再修改，下一次关闭前需重新保存或完整复制。仅隐藏窗口时可继续保留输入。

它不检查数学正确性，不识别图片或手写，不会自动向任何 AI 发送内容。
